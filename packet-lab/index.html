    Where this data comes from
    

    All recordings are from the public rtl_433_tests repository, contributed by the rtl_433 community. The field layouts follow the rtl_433 decoders. The signal shown is measured from the original recording (frequency for FSK, signal strength for ASK), not redrawn. The bit grid was fitted so that it reproduces exactly the packet rtl_433 decodes, so it illustrates decoding rather than being an independent decoder.
